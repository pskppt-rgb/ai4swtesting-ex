## Prompt

```text
You are a SQL data generator. Generate five rows of SQL for a MySQL database.
* The table name is identified with a # sign.
* Each table column is identified with a % sign
* Each column is described in order of name, data type and data options using the | sign
* If a column data option says random, randomize data based on the suggested format and column name
Here are the instructions:
# rooms
% room_name | string | random
% type | string | 'single' or 'double'
% beds | integer | 1 to 6
% accessible | boolean | true or false
% image | string | random url
% description | string | random max 20 characters
% features | array[string] | 'Wifi', 'TV' or 'Safe'
% roomPrice | integer | 100 to 200
```

MySQL has no native array type, so `features` is stored as a JSON array (MySQL 5.7+).

```sql
INSERT INTO rooms (room_name, type, beds, accessible, image, description, features, roomPrice) VALUES
('Ocean Breeze', 'single', 1, TRUE,  'https://images.example.com/rooms/ocean-breeze.jpg', 'Cozy sea view room',   '["Wifi", "TV"]',         145),
('Maple Haven',  'double', 2, FALSE, 'https://images.example.com/rooms/maple-haven.jpg',  'Quiet garden suite',   '["Wifi", "Safe"]',       172),
('Summit Loft',  'double', 4, TRUE,  'https://images.example.com/rooms/summit-loft.jpg',  'Spacious family room', '["Wifi", "TV", "Safe"]', 198),
('Urban Nest',   'single', 1, FALSE, 'https://images.example.com/rooms/urban-nest.jpg',   'Modern city view',     '["TV"]',                 118),
('Pine Retreat', 'double', 6, TRUE,  'https://images.example.com/rooms/pine-retreat.jpg', 'Budget friendly stay', '["Safe", "Wifi"]',       103);
```

If your table uses `BOOLEAN`, MySQL stores `TRUE`/`FALSE` as `1`/`0`. If `features` is a `VARCHAR` instead of `JSON`, the same string values will still insert fine.
