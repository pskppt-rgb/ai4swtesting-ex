## Response

```xml
<?xml version="1.0" encoding="UTF-8"?>
<guest>
  <fullname>Marisol Okonkwo-Lindqvist</fullname>
  <age>38</age>
  <vip>true</vip>
  <email>marisol.okonkwo@example.com</email>
  <favouriteRooms>
    <room>204</room>
    <room>512</room>
    <room>1108</room>
  </favouriteRooms>
  <address>
    <street>47 Willowbrook Lane</street>
    <city>Brighton</city>
    <postcode>BN1 4QT</postcode>
  </address>
</guest>
```

XML has no native arrays, so each favourite room becomes its own `<room>` element inside `<favouriteRooms>`.
